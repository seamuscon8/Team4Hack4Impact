1. Team 4 Haircut Project

2. This is a haircut website as part of the Hack4Impact bootcamp, it allows users to book appointments with certain barbers. And it allows to add new barbers. Going to be handed off eventually to an actual barber.

3. GitHub repository link:
   https://github.com/seamuscon8/Team4Hack4Impact
4. Live Vercel link:
